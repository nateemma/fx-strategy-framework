Return = Sharpe × vol = Sharpe × leverage, so return is a dial; the real gate is **Sharpe**. A single FX factor at Sharpe 0.3–0.5 is below the bar for a leveraged standalone (levering a 0.3-Sharpe book to 9% return needs 30% vol → ~90% DD). The value proposition is uncorrelated, scalable alpha that works when crypto momentum dies (the original bear-market question).

**How to apply:** Judge the FX program on **portfolio Sharpe and the ~8–10% levered-at-~10%-vol return**, not on any single factor's unlevered return. Don't present a lone factor's 2% as the product. If a future design tops out below ~8% / Sharpe ~0.7, flag it against this bar.
